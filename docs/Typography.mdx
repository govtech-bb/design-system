# Typography

Complete typography system for the GOV.BB design system. Use the **Heading** component for headings and the **Text** component for body text, labels, and inline elements.

## Usage

```jsx
import { Heading, Text } from '@govtech-bb/react';

// Headings
<Heading as="h1">Page Title</Heading>
<Heading as="h2" weight="semibold">Section Title</Heading>
<Heading as="display" align="center">Hero Title</Heading>

// Text
<Text as="p">Regular paragraph text</Text>
<Text as="label" weight="semibold">Form Label</Text>
<Text as="span" size="caption" className="text-gray-600">Helper text</Text>
```
